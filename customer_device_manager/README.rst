This module makes it possible for our customers to manage their devices:

- assign devices to users of their company

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_

Configuration
=============

Add a user of the company to the customer_team_manager group.

Usage
=====

The user is a portal user. It can access this app through the /web URL.
